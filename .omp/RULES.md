# Жёсткие правила omp-lite

Действуют всегда. Детали: `AGENTS.md`, `dev/PROCESS.md`, `dev/DECISIONS.md`. Порядок работы: skill `omp-lite-engineering`.

## Перед работой

- Сначала документация OMP.
- Проверь PROCESS, DECISIONS, BACKLOG, README модуля.
- Оцени в SP. Больше двух — план владельцу.
- Делай только заказанное.

## Код

- Кратчайшее рабочее решение.
- Минимум строк и символов.
- Код, данные и тексты раздельно.
- Код модуля: `index.js`. Ресурс без кода допустим.
- README модуля обязателен.
- Тест обязателен для написанного кода.
- Без новых зависимостей без согласия.
- Удаляй мёртвое и дубли.

## Проверка

- Запусти реальный вход.
- Запусти тест модуля.
- Перед `main` запусти все тесты.
- Покажи вывод.
- Сверь дифф с заказом.

## Доставка

- Ветка, один коммит.
- Обнови README и DECISIONS.
- Merge в `main`, push, удали ветку.

## Общение

- Простой русский, короткие фразы.
- Дислексия важнее прочих правил.
