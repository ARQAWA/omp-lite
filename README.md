# omp-lite

omp-lite — репозиторий будущего модульного обвеса для OMP.

Подготовлены структура репозитория и процесс разработки. В `src/modules/` лежат сырые снимки работы над установленным OMP. Механизм установки не реализован.

Готовая поставка пока не создаётся. Способ сборки и установки не выбран.

| Зона | Назначение |
| --- | --- |
| Корень | Входная документация; не устанавливаемый пакет |
| [`dev/`](dev/README.md) | Среда разработки: настройки, материалы агентов, скрипты, все тесты и приёмка |
| [`src/`](src/README.md) | Исходники будущего продукта: модули и их ресурсы |
