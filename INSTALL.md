# Установка надстройки в OMP

**Сейчас процедура установки не описана. Не изменяй установленный OMP.**

Это единственный канонический документ установки надстройки в уже установленный OMP. Он не описывает установку самого OMP или настройку рабочего места разработчика. Для установки не требуется исполнять процесс разработки.

## Текущий сценарий

1. Прочитай состояние продукта в [src/README.md](src/README.md) и [src/modules/README.md](src/modules/README.md).
2. Если документы согласованы и подтверждают, что механизм установки не реализован, сообщи точно: «Установка не выполнена: механизм установки ещё не описан.»
3. Заверши без изменения файлов, настроек, учётных данных и пакетов.

Не выполняй `pi install` или `npm install`, не придумывай OMP CLI и не копируй и не подключай корень Git-репозитория. Не выводи способ установки из названий или структуры каталогов.

При расхождении документов ничего не устанавливай: сообщи конкретное расхождение и заверши без изменений.

## Граница будущей поставки

Устанавливаемый состав будет явным списком продуктовых файлов, определённым отдельным установочным контрактом, а не рекурсивным подхватом дерева. `dev/`, все тесты, `AGENTS.md` и прочая документация разработки исключены из установки. README сами по себе не являются ресурсами OMP.

Сейчас это процедурная защита; механизм установки, упаковка и техническая проверка состава поставки не реализованы.
