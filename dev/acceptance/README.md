# Приёмка поведения

Здесь размещаются сценарии и свидетельства ручной и интеграционной приёмки будущего поведения. Они отделены от [автоматических тестов](../tests/README.md) и не устанавливаются в OMP.

Существующих результатов приёмки здесь нет. Будущее свидетельство должно указывать проверенное поведение, условия запуска, наблюдаемый результат и ограничения проверки. Текущая проверка структуры не является свидетельством работающего харнеса.
