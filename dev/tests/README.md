# Автоматические тесты

Все автоматические тесты находятся в служебном дереве и не устанавливаются в OMP.

- [harness/](harness/README.md) — тесты наблюдаемого поведения модулей продукта.
- [repository/](repository/README.md) — тесты поведения будущих служебных инструментов.

Раннер пока не выбран, тестов нет. Сценарии и свидетельства ручной и интеграционной приёмки хранятся отдельно в [acceptance/](../acceptance/README.md).
