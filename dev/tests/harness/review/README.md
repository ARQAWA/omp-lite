# review tests

`bun test dev/tests/harness/review`.

Проверяют скрипт `src/modules/review/index.js` через его экспорт.
Данные: маленький JSONL во временной папке.

- реплики: только текст владельца и агента;
- срез начинается с заданной реплики;
- изменённая фактура не проходит сверку SHA-256;
- цитата, которой нет в срезе, ловится.

Модели и OMP не запускаются.
Живые пробы описаны в README модуля.
