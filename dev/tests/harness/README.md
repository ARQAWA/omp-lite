# Тесты модулей продукта

Организация зеркальна продуктовым модулям: `dev/tests/harness/<module-name>/` проверяет `src/modules/<module-name>/`. Правила модулей: [src/modules/README.md](../../../src/modules/README.md).

Тесты должны детерминированно проверять наблюдаемое поведение, границы и ошибки, быть изолированными и не использовать реальный сетевой доступ. Они вправе импортировать проверяемые модули, но сами остаются вне устанавливаемого дерева.

Раннер: `bun test dev/tests/harness`. Каталог теста создаётся вместе с модулем. Профили агентов-разработчиков находятся отдельно в [dev/agents/](../../agents/README.md).
