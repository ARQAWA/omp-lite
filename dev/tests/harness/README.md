# Тесты модулей продукта

Будущая организация зеркальна продуктовым модулям: `dev/tests/harness/<module-name>/` проверяет `src/modules/<module-name>/`. Правила модулей: [src/modules/README.md](../../../src/modules/README.md).

Тесты должны детерминированно проверять наблюдаемое поведение, границы и ошибки, быть изолированными и не использовать реальный сетевой доступ. Они вправе импортировать проверяемые модули, но сами остаются вне устанавливаемого дерева.

Сейчас тестов и каталогов модулей нет; раннер не выбран. Не создавай тестовые каталоги для несуществующих модулей. Профили агентов-разработчиков находятся отдельно в [dev/agents/](../../agents/README.md).
