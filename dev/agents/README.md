# Агенты-разработчики

Это место только для инструкций и профилей агентов, разрабатывающих репозиторий.

- [omp-upgrade/](omp-upgrade/SKILL.md) — обновление харнеса на новую версию OMP. Агент приходит к нему по строке в `AGENTS.md`; OMP сам его не загружает.
  `verify` и `probe` сверяют запросы по [contract.json](omp-upgrade/contract.json): для `eval` проверяют ссылку на справку, для `glob` — порядок правила `file_work` и описания.

Содержимое этого каталога — не промпты, навыки и профили установленного харнеса. Его нельзя подключать к OMP как продуктовый ресурс. Правила границы: [AGENTS.md](../../AGENTS.md). Ресурсы конкретного продуктового модуля принадлежат его каталогу в [src/modules/](../../src/modules/README.md).
