**Причина:** Владелец хотел, чтобы Luna работала быстрее. Приоритет работает, хотя в ответе стоит `default`.

## Действующие требования

1. Транспорт Codex в OMP перенастроен минимально, ради скорости.
2. Перенастройка это один хук `before_provider_request`. Он работает только на запросах к Codex.
3. Хук оставляет обычный запрос Full Responses. Lite не включается.
4. Хук ставит `parallel_tool_calls: true`.
5. Хук ставит `reasoning.context: all_turns`.
6. Хук ставит `text.verbosity: low`.
7. Хук не меняет уровень reasoning effort, выбранный владельцем.
8. Для модели с `Luna` в названии хук ставит `service_tier: priority`.
9. Запросы к Codex уходят из OMP с параметрами, которые ставит хук. Владелец потребовал доказательство этого.
10. Модуль остаётся в репозитории.
11. Модуль это сырой снимок рантайма без правок, отдельным модулем.
12. README описывает модуль по факту.
13. README минимален, без воды.
14. Файл модуля ставится в рантайм из репозитория через установочный контракт.
