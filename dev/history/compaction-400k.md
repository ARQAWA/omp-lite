### 2026-11-07 — Порог 400k для Claude Code и DeepSeek через OpenCode Go

**Решение:** Сжатие контекста запускается на 400k токенов. Порог нужен моделям Claude Code с окном в миллион токенов и DeepSeek V4.1 Flash из OpenCode Go. Агент записал порог в конфиг OMP значением `f400000`, без плагина. Это 12 моделей Claude и одна модель DeepSeek. Окно модели осталось миллионным. Остальные модели агент не тронул. Само сжатие на 400k агент не запускал. Он проверил только расчёт порога на 399 999, 400 000 и 400 001 токене.
**Основание:** Владелец попросил сжатие на 400k для DeepSeek и Claude Code с окном в миллион. Потом он уточнил: нужны Claude Code по подписке и DeepSeek по подписке OpenCode Go. Он спросил, какие модели Claude настроены и где настроен OpenCode Go. Он принял ответ агента. Позже он снова назвал автосжатие на 400k в списке переноса. Сессия `01a1b487-dd8d`, реплики 84, 85, 87, 89, 91, 93, 95, 96, 98.
**Причина:** Владелец причину не назвал. Он говорил о моделях с окном в миллион токенов.
**Статус:** в силе (список моделей расширен позже)
**Запись:** нет
**Коммиты:** нет (настройка стояла в живом конфиге; в репозиторий попала 2026-11-08 в `7b45f59`)

### 2026-11-08 — Сжатие 400k первым модулем репозитория

У OpenCode DeepSeek и у Claude порог уже был. Для `deepseek/deepseek-flash` порога не было. Для Sol и Terra он не был задан. Он также потребовал, чтобы нестандартный runtime config лежал в репозитории и входил в `INSTALL.md`. Тот же текст заказа владелец прислал ещё два раза (реплики 8 и 9). **Причина:** Владелец хотел сохранить настройки рантайма в репозитории. Установка на новой машине должна давать те же настройки.

### 2026-11-08 — Установка через контракт

**Решение:** Настройки порогов ставятся в рантайм через установочный контракт. В манифесте запись: `src/modules/compaction-400k/thresholds.yml` в `config.yml`, режим `merge`. Слияние не заменяет личный `config.yml`.
**Основание:** Владелец потребовал, чтобы всё из репозитория ставилось в рантайм через установочный контракт. Раньше он уже требовал держать runtime config в репозитории и в `INSTALL.md`. Сессия `01a1bb5e-d176`, реплика 534. Сессия `01a1b7e8-de03`, реплика 7.
**Причина:** Репозиторий и рантайм должны совпадать. Установка идёт по одному описанию.

## Действующие требования

1. Автосжатие запускается на 400k токенов контекста.
2. Модели Claude Code по подписке с окном 1M сжимаются на 400k токенов.
3. DeepSeek по подписке OpenCode Go сжимается на 400k токенов.
4. GPT-6.1 Sol и GPT-6.1 Terra с окном 500k сжимаются на 400k токенов.
5. Все модели Fable (5, 5.1, 5.2) имеют порог 400k, как Sonnet и Opus. Владелец назвал и Haiku.
6. Сжатие 400k остаётся в репозитории отдельным модулем.
7. Модуль хранит работу из рантайма сырым снимком, без правок, отдельным модулем.
8. Пороги входят в runtime config. Конфиг лежит в репозитории и ставится через установочный контракт.
9. README описывает модуль по факту.
10. README минимален, без воды.
