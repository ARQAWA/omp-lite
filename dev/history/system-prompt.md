## Действующие требования

1. У omp-lite есть свой системный промпт главного агента. Владелец считает его критическим пунктом.
2. За основу взят системный промпт Cursor Desktop для GPT-5.5 из локального снимка реверса. Интернет не используется.
3. Текст Cursor 5.5 сохраняется. Убираются и меняются только явные места, не подходящие нашим тулам. Правки минимальные.
4. Промпт описывает наши текущие тулы OMP и не расходится с их описаниями из `cursor-tools`. Он остаётся максимально близкой копией промпта Cursor.
5. Везде вместо Cursor стоит OMP. Модель по имени не называется: просто агент.
