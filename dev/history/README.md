# История решений по модулям

Здесь лежит по файлу на каждый модуль из [src/modules/](../../src/modules/README.md). Файл рассказывает, как и почему менялись решения по модулю.

- Источник: переписки сессий OMP этого билда, с 2026-11-07.
- Запись: дата, решение, основание со ссылкой на сессию и реплику, причина.
- Действующие решения записаны в [DECISIONS.md](../DECISIONS.md). При споре прав `DECISIONS.md`.
- Сырые переписки в репозиторий не входят.
- Каталог не устанавливается в OMP.
