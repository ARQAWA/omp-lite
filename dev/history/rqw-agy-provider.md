# История rqw-agy-provider

## 2026-11-22 — рождение модуля

**Решение:** провайдер `agy` реализован расширением с собственным api `agy-api` и `streamSimple`, а не models.yml-шлюзом. Авторизация из keychain agy, обмен refresh-токена внутри расширения.

**Основание:** владелец просил нативную работу без посредников: «omp будет слать запросы напрямую, без митм прокси... пакет внутренних реквестов собирается так же нативно, как в антигравити». Первый вариант (локальный google-gemini-шлюз на 8948 и блок в models.yml) отвергнут и удалён.

**Реверс:** механика снята митм-прокси с agy 1.5.14 (дампы у владельца): конверт `project`/`requestId`, labels по алфавиту, `systemInstruction` role user, `tools` с legacy `parameters` и свёрнутыми в description запрещёнными ключами, SSE-события `{response:...}`, `sessionId` отрицательным int63.

**Проверка:** живые вызовы Neon/Hydrogen/Argon/xhigh, тул-колы с записью файла, `cachedContentTokenCount` виден в usage.

## 2026-11-23 — Паритет с agy по дампам и своя квота

**Решение:** провайдер сверен с полными дампами agy 1.5.14 (35 вызовов модели) и поправлен своим кодом:
1. токен берётся из keychain agy, при пустом keychain — из файла `~/.gemini/antigravity-cli/antigravity-oauth-token`;
2. xhigh шлёт `thinkingLevel: 100`;
3. `sessionId` — случайный int64 со знаком;
4. `id` тула берётся из ответа сервера и уходит в `functionCall` и `functionResponse`, результат тула — ходом `role: "model"`;
5. мысль перед вызовом тула в историю не возвращается;
6. `minimum`, `minLength`, `minItems` в схемах тулов идут полями;
7. своя квота: `POST retrieveUserQuotaSummary` с телом `{project}`, бакеты `gemini-weekly` и `gemini-5h` уходят в `omp usage` через `usage` провайдера.

**Основание:** владелец попросил убедиться, что транспорт работает как оригинал по реверсу, и добавить в виджет юзадж Gemini на неделю и 5 часов. Правило владельца: «мы пишем свой нет код», «мы не переиспользуем чужой код, готовый, связанный с неткодом», «встраиваем в OMP конвенциональным способом». Из OMP — только крючки `registerProvider`, `streamSimple`, `usage`.

**Причина:** agy с 13:23 пишет токен в файл, когда keychain недоступен; провайдер с одним keychain не входил. Остальное — отличия формы запроса, снятые повторным разбором дампов.

**Не внесено:** типы в схемах тулов строчными (сервер принимает), одна part в `systemInstruction`, телеметрия `last_execution_id` и шаги, служебный вызов `writeTrajectoryAcls`. Реверс не снял: ошибки 429 и 5xx, продолжение длинного ответа, картинки в ответе тула, параллельные тулы.

**Найдено вживую:** сервер Google отвечает `429 RESOURCE_EXHAUSTED` на штатный промпт OMP без `SYSTEM.md`. Фильтр срабатывает на строку `You are omp's trusted coding assistant` (`packages/coding-agent/src/prompts/system/system-prompt.md:1`, OMP 19.1.1): в любом регистре и не обязательно первой строкой. С другим именем вместо `omp's` ответ `200`. Промпт из `SYSTEM.md` строки не содержит, с ним вызовы проходят. Обход фильтра не делался: решение за владельцем.

**Проверка:** `bun test dev/tests` — 121 pass. Живые вызовы штатным входом с промптом `SYSTEM.md`: xhigh — `thinkingLevel: 100`, HTTP 200; тул `read` — HTTP 200 на обоих ходах, `id` от сервера, `cacheRead` 796; `omp usage --json` — отчёт `agy` с бакетами недели и 5 часов.
