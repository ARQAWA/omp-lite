# История rqw-agy-provider

## 2026-11-22 — рождение модуля

**Решение:** провайдер `agy` реализован расширением с собственным api `agy-api` и `streamSimple`, а не models.yml-шлюзом. Авторизация из keychain agy, обмен refresh-токена внутри расширения.

**Основание:** владелец просил нативную работу без посредников: «omp будет слать запросы напрямую, без митм прокси... пакет внутренних реквестов собирается так же нативно, как в антигравити». Первый вариант (локальный google-gemini-шлюз на 8948 и блок в models.yml) отвергнут и удалён.

**Реверс:** механика снята митм-прокси с agy 1.5.14 (дампы у владельца): конверт `project`/`requestId`, labels по алфавиту, `systemInstruction` role user, `tools` с legacy `parameters` и свёрнутыми в description запрещёнными ключами, SSE-события `{response:...}`, `sessionId` отрицательным int63.

**Проверка:** живые вызовы Neon/Hydrogen/Argon/xhigh, тул-колы с записью файла, `cachedContentTokenCount` виден в usage.
