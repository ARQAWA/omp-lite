# История решений: communication

Источник: переписки сессий OMP этого билда, с 2026-11-07.
Действующие решения записаны в [DECISIONS.md](../DECISIONS.md).

## Хронология

### 2026-11-13 — Общение с пользователем только у главного агента

**Решение:** блоки `<special_user_requests>`, `<mixed_requests>` и `<working_with_the_user>` вынесены из `SYSTEM.md` в правило OMP `communication-main` с `agents: main`. Все сабагенты получают правило `communication-subagent` с `agents: "!main"`: без разговоров во время работы, полный финальный отчёт тому, кто дал задачу. Родные правила OMP, без хука и патча.
**Основание:** слова владельца: «Надо убрать это. Такого быть не должно вообще»; «туда перенести всю вот эту часть про коммуникацию полностью ... вставлять именно в main agent ... чтобы саб-агенты их не получали»; «найти какой-то native way ... без патчинга в рантайме». Сессия `01a1d13b-8491`.
**Причина:** сабагенты получали правила для пользователя («be very concise», «50-70 lines») и сжимали отчёты.
**Статус:** в силе
**Запись:** D-067
**Коммиты:** `6bc040c`

### 2026-11-14 — Заметка сабагентам просит максимум полезной нагрузки

**Решение:** в заметку сабагентам добавлена одна фраза: сделать финальный отчёт максимально глубоким, широким и плотным по фактам.
**Основание:** слова владельца: «надо максимизировать тех ответы, полезную нагрузку надо максимизировать каким-то образом»; на вопрос «вношу эти четыре правки? да или нет.» ответ «да». Сессия `01a1d13b-8491`.
**Причина:** отчёты сабагентов должны нести всё, что нужно родителю, чтобы не повторять работу.
**Статус:** в силе
**Запись:** D-070
**Коммиты:** `c8ea51f`

## Действующие требования

1. Блоки общения с пользователем получает только главный агент.
2. Каждый сабагент получает одну заметку: без разговоров в работе, полный финальный отчёт для агента-родителя.
3. Механизм родной для OMP, без патча рантайма и без копии текста в каждом профиле.
4. Блоки перенесены из `SYSTEM.md` без изменений.
5. Правила `<mixed_requests>` (D-057), включая вопрос про следующий шаг агента, живут в `communication-main`.
6. Заметка сабагентам несёт фразу про максимум полезной нагрузки (D-070).
7. Заметка доходит до каждого сабагента одним родным правилом, без копий по профилям.

## Отменённое

1. «Убрать "be very concise" и "50-70 lines" полностью» (слова владельца: «Надо убрать это. Такого быть не должно вообще», 2026-11-13, сессия `01a1d13b-8491`, реплика 56). Заменено частично: для главного агента строки остались и переехали в `communication-main` (реплика 65), сабагенты их не получают.
