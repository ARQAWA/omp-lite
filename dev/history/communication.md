## Хронология

### 2026-11-13 — Общение с пользователем только у главного агента

**Решение:** блоки `<special_user_requests>`, `<mixed_requests>` и `<working_with_the_user>` вынесены из `SYSTEM.md` в правило OMP `communication-main` с `agents: main`. Все сабагенты получают правило `communication-subagent` с `agents: "!main"`: без разговоров во время работы, полный финальный отчёт тому, кто дал задачу. Родные правила OMP, без хука и патча.
**Основание:** слова владельца: «Надо убрать это. Такого быть не должно вообще»; «туда перенести всю вот эту часть про коммуникацию полностью ... вставлять именно в main agent ... чтобы саб-агенты их не получали»; «найти какой-то native way ... без патчинга в рантайме». Сессия `01a1d13b-8491`.
**Причина:** сабагенты получали правила для пользователя («be very concise», «50-70 lines») и сжимали отчёты.
**Статус:** в силе
**Запись:** D-067
**Коммиты:** коммит ветки `communication-split`

## Действующие требования

1. Блоки общения с пользователем получает только главный агент.
2. Каждый сабагент получает одну заметку: без разговоров в работе, полный финальный отчёт для агента-родителя.
3. Механизм родной для OMP, без патча рантайма и без копии текста в каждом профиле.
