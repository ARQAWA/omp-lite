Сессия `01a1b548-69dc`, реплика 12, 23:31.
**Причина:** Sharpshooter не сохранял воспоминания: в логе стояло, что модели для разбора нет (реплика 3). В одном профиле работает один backend памяти (реплика 7). Модель EmbeddingGemma 2 уже стояла на машине.
**Статус:** в силе

## Действующие требования

1. Backend памяти — Mnemopi, Sharpshooter выключен.
2. Mnemopi ищет через EmbeddingGemma 2 на локальном Ollama.
3. Роль `memory` идёт на DeepSeek Flash с Max, запас — OpenCode Go DeepSeek Flash с Max. Сейчас обе записи указывают на `opencode-go/deepseek-v4.1-flash:max`. Отдельной локальной модели для разбора фактов нет.
4. Mnemopi настраивается на лучшую скорость и качество. Режимы максимальной формы владелец не заказывал отдельным словом.
5. Подсказки промптов после хода включены и работают, как в Codex CLI, штатной настройкой OMP.
6. Тема и статусная строка остаются в сохранённом конфиге.
7. В пикере только нужные провайдеры: сейчас `anthropic`, `openai-codex`, `opencode-go`. Остальные скрыты через `disabledProviders`.
8. Роль `default` остаётся на DeepSeek Flash (сейчас `opencode-go/deepseek-v4.1-flash:max`).
9. Рабочий конфиг хранится в репозитории и входит в установочный контракт. Всё из репозитория ставится через контракт.
10. Настройки Mnemopi входят в установочный контракт.
11. Баннер обновления при старте не показывается.
12. Артефакты вывода: порог 50 КБ, голова 50 КБ, хвост 0 КБ и 0 строк, файл артефакта до 32 МБ.
