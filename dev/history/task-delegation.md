Блок выдаёт сообщение: вызовы заблокированы, для явного делегирования есть тул `task`. Менять сам OMP не нужно. Это текстовый фильтр, не изоляция. Алиасы и код через `%load` могут пройти. Защита не абсолютная.
**Основание:** владелец спросил, что это за тулы (реплика 27, 07:30). Агент объяснил: это функции внутри `eval`, они запускают саб-агентов мимо `task` (реплика 28). ## Действующие требования

1. Саб-агенты не запускаются сами. Только по прямой просьбе пользователя, по скиллу, `AGENTS.md` или другому указанию.
2. Правило то же, что в Codex CLI: та же строка и тот же смысл, из описания `spawn_agent`.
3. Строка лежит в описании тула `task`, как в Codex. В системном промпте её нет.
4. Глубина исследования не даёт права запускать саб-агентов.
5. Запрет `task` доходит до модели на всех моделях, и на Claude с префиксом `_` у имён тулов.
6. В описании `task` нет приказа использовать `scout`. `scout` доступен по просьбе пользователя.
7. На широкий вопрос, где хочется делегировать, ни один `task` не запускается без просьбы.
8. Функции `agent()` и `workpool()` убраны из `eval` в рамках исходников OMP: подсказки удалены, прямые вызовы блокирует текстовый фильтр, сам OMP не меняется. Явное делегирование идёт через `task`.
9. Блок это текстовый фильтр, не изоляция. Его можно обойти, он может сработать по ошибке, защита не абсолютная.
10. В описании `eval` JavaScript на Bun стоит по умолчанию. Python остаётся и помечен как редкий случай для особых библиотек.
11. Агенты ищут и читают файлы тулами `read`, `grep` и `glob`. Описание `eval` говорит об этом и оставляет `eval` для вычислений.
