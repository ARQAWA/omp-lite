# Служебный загрузчик Windows-файлов

Скачивает закреплённые файлы для сборки расширения `ompcli` и сверяет SHA-256.

Пины лежат в продуктовом ресурсе `src/modules/ompcli/runtime.json`. Скрипт находит его
через [install.manifest.json](../../../install.manifest.json), раздел `vscode`, поэтому
второй копии пинов нет.

## Вход

```text
bun dev/scripts/ompcli-runtime/index.js [file] [asset]
```

`asset` — ключ из `runtime.json`: `omp`, `bun` или `model`. Без аргументов берётся `omp`
и путь `dist/ompcli/runtime/omp.exe`.

## Поведение

`fetchRuntime(file, asset, request)` возвращает `cached` или `downloaded`.
Проверенный файл с тем же размером и хешем не скачивается повторно.
Загрузка идёт потоково во временный файл рядом с целью. Размер и SHA-256 сверяются до
переименования, поэтому ошибка оставляет прежний файл. Временный файл удаляется всегда.

## Границы

Скрипт не устанавливается вместе с продуктом и не импортирует продуктовый код.
Запуск Windows-файлов на Mac не выполняется: только скачивание и хеш.
