# Настройки разработки

Здесь размещаются настройки среды разработки этого репозитория, не настройки установленного OMP и не ресурсы продуктовых модулей.

Сейчас активных конфигураций и механизма их автоматической загрузки нет. Настройки конкретного модуля принадлежат его каталогу в [src/modules/](../../src/modules/README.md).

Карта среды разработки: [dev/README.md](../README.md). Граница разработки и продукта: [AGENTS.md](../../AGENTS.md).
