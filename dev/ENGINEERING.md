# Инженерные правила omp-lite

## Инварианты

- Минимум строк и символов. Это про файлы в репозитории: код и тесты. Код минимально достаточный: минимум строк кода. Тесты минимально достаточные: минимум строк тестов. Это не про общение: ответы, отчёты и ревью это правило не режет.
- Без новых зависимостей без согласия.
- Удаляй мёртвое и дубли.
- Покажи вывод.
- Обнови README и DECISIONS.

## Структура

```text
src/modules/<name>/
  index.js
  <name>.json
  README.md
dev/tests/harness/<name>/
  <name>.test.js
```

- Тексты и данные — отдельными JSON или YAML.
- README: назначение, вход, хуки, установка, выключение, тест.
- Ресурс без кода: YAML/JSON плюс README.
- Тест зеркалит модуль.

## Порядок

1. Найди штатный способ в исходниках OMP.
2. Прочитай README и тест модуля.
3. Напиши минимальный код.
4. Проверь реальным входом и тестом.
5. Ветка, коммит, merge, push.
