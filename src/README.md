# Исходники харнеса

`src/` предназначен только для исходников продукта и его ресурсов. Сейчас реализованных и устанавливаемых модулей нет; механизм установки не реализован.

Единственная подструктура сейчас — [modules/](modules/README.md), место самостоятельных модулей. В дереве находятся только два ориентационных README; они сами по себе не являются ресурсами OMP.

Отдельная готовая поставка пока не создаётся. `dist/` понадобится только при выборе способа сборки; общее ядро `core/` заранее не выделяется.

Все тесты продукта находятся вне этого дерева, в [dev/tests/harness/](../dev/tests/harness/README.md). Ссылка из документации допустима; runtime-зависимости от среды разработки и корневых инструкций недопустимы.

Единственный источник процедуры установки — [INSTALL.md](../INSTALL.md). Текущее действие установщика — сообщить об отсутствии устанавливаемых модулей и завершить без изменений установленного OMP.
