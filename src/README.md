# Исходники харнеса

`src/` предназначен только для исходников продукта и его ресурсов. Сейчас здесь сырые снимки работы над установленным OMP. Устанавливаемый состав задан [install.manifest.json](../install.manifest.json), процедура — [INSTALL.md](../INSTALL.md).

Единственная подструктура сейчас — [modules/](modules/README.md), место самостоятельных модулей. README сами по себе не являются ресурсами OMP.

Отдельная готовая поставка пока не создаётся. `dist/` понадобится только при выборе способа сборки; общее ядро `core/` заранее не выделяется.

Все тесты продукта находятся вне этого дерева, в [dev/tests/harness/](../dev/tests/harness/README.md). Ссылка из документации допустима; runtime-зависимости от среды разработки и корневых инструкций недопустимы.

Единственный источник процедуры установки — [INSTALL.md](../INSTALL.md); состав — [install.manifest.json](../install.manifest.json).
