# define-goal

Команда `/define-goal` вместо встроенной `/guided-goal`. Текст интервью тот же.

Встроенную команду OMP переименовать нельзя: имя вшито в бинарь. Поэтому три части.

- `define-goal.md` — текст интервью, данные модуля.
- `index.js` — команда `/define-goal`, скрытие `/guided-goal` из автокомплита.
- Команда сначала включает тул `goal`, потом отправляет текст интервью.

Тул `goal` по умолчанию выключен. Встроенная команда включала его сама, поэтому копия текста без этого шага ломала создание цели.

**Вход:** `~/.omp/agent/extensions/define-goal.js` и `~/.omp/agent/extensions/define-goal.md`.

**Выключить:** удалить оба файла. Вернётся встроенная `/guided-goal`.

**Тесты:** `bun test dev/tests/harness/define-goal`.
