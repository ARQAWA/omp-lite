# workflow

Расширение OMP. Дописывает подсказку о порядке работы в конец каждого сообщения владельца при сборке запроса. В истории и интерфейсе вставки нет.

**Вход:** `~/.omp/agent/extensions/workflow.js` и `workflow.json`.

**Текст подсказки:** ключ `block` в `workflow.json`. Подсказка повторяет четыре параметра приёмки владельца: ничего незаказанного, точные указания точно, ничего не забыто, самый простой путь. И правило: незаказанная часть кажется критичной, сначала спроси владельца.

**Пропуски:** сабагенты, сессия без `ctx.agent`, повторная вставка. Подсказка идёт только основному агенту.

**Выключить:** удалить файл `workflow.js`.

**Тесты:** `bun test dev/tests/harness/workflow`.
