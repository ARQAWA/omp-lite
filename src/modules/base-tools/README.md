# base-tools

Тонкий тул `files`: карта проекта и широкий поиск одним вызовом. Закрывает потолок 200 путей у родного `glob` и страницу в 20 файлов у `grep`. Не зависит от git.

**Вход:** `~/.omp/agent/extensions/base-tools.js`, ставится по [манифесту](../../../install.manifest.json).

**Поведение `files` без `pattern`:**
- обходит всю папку `path` по маске `glob`;
- первая строка: `total N files`;
- пути сгруппированы по папкам: строка `src/`, ниже имена с отступом;
- последняя строка: `[all N files listed]` или `[N files: K listed, the rest folded into M directories]`;
- список больше бюджета: глубокие папки сворачиваются в `dir/ (N files)`, счёт в последней строке сходится с `N`;
- свёрнутая карта не влезла: ответ уходит целиком, OMP кладёт его в `artifact://N`;
- бюджет ответа: `tools.artifactSpillThreshold` минус 5 КБ;
- `hidden` по умолчанию `true`, `gitignore` по умолчанию `true`;
- `node_modules` и `.git` не показываются;
- таймаут 30 секунд это ошибка, не частичный список.

**Поведение `files` с `pattern`:**
- первый проход движка `grep` в режиме `count`: файлы и число совпадений;
- второй проход в режиме `content` с `maxCountPerFile: 1`: первая строка совпадения на файл;
- первая строка: `N files, M matches, searched K of T files`;
- файлы идут по убыванию числа совпадений, потом по пути;
- у файла: `path (N matches): первая строка`, строка обрезана до 512 байт;
- хвост сворачивается по папкам: `dir/ (N files, M matches)`; если не влезает, по верхним папкам;
- файлы больше 4 МиБ названы в строке `searched in part (first 4 MiB): ...`;
- пустой шаблон из пробелов это ошибка; негодная регулярка ищется буквально, как у `grep`;
- `\n` в шаблоне включает многострочный поиск, как у `grep`;
- `case` по умолчанию `true`; `case: false` ищет без учёта регистра;
- `glob` с папкой берёт все файлы внутри неё, как у `grep`;
- `node_modules` скрыт даже при явной маске; `node_modules_backup` не скрыт;
- все проходы движка делят один срок 30 секунд;
- `K of T` это счёт движка: бинарный файл он считает просмотренным.

**Поля:** `path`, `glob`, `pattern`, `case`, `hidden`, `gitignore`.

**Движок:** `glob` и `grep` из `@oh-my-pi/pi-natives`, через `await import`. В тесте движок подменён.

**Пометка «костыль»:** `omp://extensions.md` не описывает импорт движка из расширения. Импорт проверен пробой и уже используется модулем `cursor-tools`. Сторож в T5 будет сверять экспорты движка после обновления OMP.

**Границы:** только локальные папки. URL и архивы остаются у родных `glob`, `grep` и `read`. Один вызов покрывает папку целиком; листания нет.

**Проверка:** `bun test dev/tests/harness/base-tools`.
Живые пробы: папка без git дала `total 6 files`; папка на 1200 файлов назвала все 1200, ответ 18 КБ, последняя строка `[all 1200 files listed]`; плоская папка 6000 файлов ушла в `artifact://0`, `read` вернул `total 6000 files`.

**Выключить:** убрать запись манифеста и файл из `~/.omp/agent/extensions/`.
