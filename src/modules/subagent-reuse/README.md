# subagent-reuse

Автоматическое переиспользование сабагента: новый агент не создаётся.

Main создаёт сабагента один раз через `task`. Дальше зовёт инструмент `reuse` с его именем. Инструмент делает `newSession()` и запускает новую задачу. История разговора начинается с нуля.

**Что остаётся.** Роль, тулы и модель. Их задаёт агент при создании. Старый контекст задачи удаляется из системного промпта.

**Что делает Main.** Ничего вручную. Он сам выбирает `reuse` для следующей независимой задачи. Маркер и ручной id не нужны. Инструмент видит только главный агент.

**Границы.** Работает с живым или припаркованным сабагентом. Запущенного агента не трогает: сначала дождись или используй `write`. Память OMP и autolearn не сбрасываются: прошлые факты могут вернуться отдельным каналом. Старые файлы сессий остаются на диске: сабагент с тулами может их прочитать. Первый запуск идёт через `task`: инструмент `reuse` не создаёт нового агента.

**Шаблон.** Срез идёт по шаблону `prompts/system/subagent-system-prompt.md` OMP 18.18.8. Он удаляет блок от строки `⁂ Context` до настоящего `⁂ Plan`, если план есть, иначе до последнего `⁂ Coop` с его первой фразой. Роль, план, Coop с `# Working Tree` и `# Peers` и Completion не меняются. Если OMP изменит шаблон, маркер надо обновить. Роль не должна содержать строку `⁂ Context`: срез начнётся с неё.

**Вход:** `~/.omp/agent/extensions/subagent-reuse.js`.

**Выключить:** удалить файл.

**Тесты:** `bun test dev/tests/harness/subagent-reuse`.
