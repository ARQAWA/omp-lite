# subagent-reuse

Переиспользование сабагента без нового агента: модель видит только новую задачу.

Работает в сессии сабагента. Если Main присылает сообщение с маркером `[task <id>#<n>]`, всё до этого сообщения скрывается из запроса к модели. Системный промпт, тулы, файл сессии и память процесса остаются прежними.

**Зачем.** Новый сабагент каждый раз собирается заново. Тёплый агент уже загружен. Полный сброс истории делает его пригодным для следующей задачи.

**Как вызвать.** Дать сабагенту id при запуске через `task`, затем послать новую задачу через `write` в `agent://<id>`. Текст начать с маркера:

```text
[task Probe#2] Complete assignment thoroughly: ...
```

Маркер проверяется в начале сообщения. Номер задачи — любое целое число.

**Что не сбрасывается.** Системный промпт и список тулов. Они заданы при создании агента и не меняются.

**Границы.** Срез действует только на запрос к модели. История сессии остаётся полной: её видят интерфейс и `history://`. Сообщение во время работы агента приходит как steer, а не как IRC, и истории не сбрасывает. Память OMP и autolearn не сбрасываются: прошлые факты могут вернуться отдельным каналом.

**Вход:** `~/.omp/agent/extensions/subagent-reuse.js`.

**Выключить:** удалить файл.

**Тесты:** `bun test dev/tests/harness/subagent-reuse`.
