# communication

Ресурсный модуль. Кода нет. Правила общения разные для главного агента и сабагентов.

**Что делает:**

- главный агент получает блоки общения с пользователем;
- сабагент получает одну короткую заметку: не говорить во время работы, дать полный финальный отчёт тому, кто дал задачу.

**Вход OMP:** родные правила OMP с полем `agents`. Хука и патча нет. Факты из исходников OMP 18.18.8:

- `discovery/builtin.ts`, `loadRules`: правила пользователя лежат в `~/.omp/agent/rules/*.md`;
- `capability/rule.ts`: поле `agents` это маски имён агентов, `main` значит главную сессию; совпадение: точное имя или `Bun.Glob(pattern).match(name)`;
- `capability/rule-buckets.ts`, `bucketRules`: правило с чужим `agents` отбрасывается; `alwaysApply: true` кладёт тело в системный промпт;
- `sdk.ts`: имя главной сессии `main`, сабагента — имя его профиля (`task`, `sonic`, `scout`, `acceptor` и другие), без имени — `sub`; родитель передаёт сабагенту все правила, каждая сессия отбирает свои;
- `prompts/system/custom-system-prompt.md`: тела правил стоят в начале промпта, сразу после списка навыков.

**Ресурсы:**

- `rules/communication-main.md` — `agents: main`, только главный агент. Три блока Cursor GPT-5.5: `<special_user_requests>`, `<mixed_requests>`, `<working_with_the_user>`. Текст перенесён из `SYSTEM.md` без изменений. `<mixed_requests>` — наше дополнение, D-057.
- `rules/communication-subagent.md` — `agents: "!main"`, все сабагенты. Заметка про финальный отчёт. Она ещё просит увеличить полезную нагрузку ответа: глубина, ширина, плотность фактов (D-070). Текст одобрен владельцем.

**`scout`.** Получает заметку, как все сабагенты. Его роль заменена ролью `explore` из Cursor: профиль в [task-delegation](../task-delegation/README.md), решение D-069.

**Смешанные сообщения.** Блок `<mixed_requests>` стоит перед `<working_with_the_user>`. Владелец диктует голосом: в одном сообщении бывают правка и вопрос, знаки препинания ненадёжны. Смешанное сообщение: агент делает только безопасную часть (ответ, ресёрч, отчёт), ничего не меняет и одной строкой спрашивает про отложенное действие. Фразу, похожую на вопрос, агент не записывает как факт. Короткий вопрос про его следующий шаг («че ждешь», «почему не поправил») это вопрос: ответ и «да или нет», без действия. Ясная одна команда выполняется без вопроса. Своё дополнение, не текст Cursor. Решение: D-057.

**Границы:** новые правила видны только в новой сессии. Решение: D-067.

**Установка:** файлы перечислены в [манифесте](../../../install.manifest.json); процедура — [INSTALL.md](../../../INSTALL.md).

**Выключить:** удалить `~/.omp/agent/rules/communication-main.md` и `communication-subagent.md`. Без первого главный агент теряет блоки общения: их нет в `SYSTEM.md`.

**Тесты:** `bun test dev/tests/harness/communication`.
