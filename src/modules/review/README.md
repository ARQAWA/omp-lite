# review

Ресурсный модуль. Кода нет. Blind и high ревью через сабагентов OMP.

**Вход:** навыки `~/.omp/agent/skills/{blindreview,highreview,reviewer}/`, агенты `~/.omp/agent/agents/{spotty,bossy}.md`.

**Вызов:** `/blindreview` и `/highreview` через `skill-alias`; нативно `/skill:blindreview` и `/skill:highreview`.

**Поток:** работа → `spotty` или `bossy` → находки → правки одним пакетом → новый проход → `CLEAN`. Ревьюер каждый раз новый и проверяет заново.

**Модели:** `spotty` — `gpt-6.1-terra` high, `bossy` — `gpt-6.1-terra` xhigh. Запасных моделей нет.

**Ограничение:** OMP не наследует историю в сабагентах. Ревьюер получает полный бриф: объект, требования, слова пользователя, согласованные решения и критерий.

**Read-only:** у ревьюеров это инструкция, не песочница. Тулы `read`, `grep`, `glob`, `bash` доступны; `bash` запрещён для правок.

**Установка:** файлы `skills/` и `agents/` перечислены в [манифесте](../../../install.manifest.json); процедура — [INSTALL.md](../../../INSTALL.md).

**Выключить:** удалить установленные файлы.

**Проверка:** реальным запуском. Постоянного теста нет: только ресурсы.
