# review

Ресурсный модуль. Кода нет. Blind и high ревью через сабагентов OMP.

**Вход:** навыки `~/.omp/agent/skills/{blindreview,highreview,selfcheck,reviewer}/`, агенты `~/.omp/agent/agents/{spotty,bossy,selfcheck}.md`.

**Вызов:** `/blindreview` и `/highreview` через `skill-alias`; нативно `/skill:blindreview` и `/skill:highreview`.

**Поток:** своя законченная работа → selfcheck-форк → проверка и правки → `spotty`/`bossy` → исправления → новый проход → `CLEAN`. Ревью чужой работы и задача только на ревью идут в `spotty`/`bossy` напрямую.

**Модели:** `spotty` — high, `bossy` — max на `deepseek/deepseek-flash`; запасной провайдер `opencode-go/deepseek-v4.1-flash` с тем же уровнем. У `selfcheck` моделей нет: наследует модель пикера. Это и есть форк по модели.

**Ограничение:** OMP не наследует историю в сабагентах. Форк получает полный бриф: объект, требования, слова пользователя, согласованные решения и критерий. Транскрипт не копируется.

**Read-only:** у ревьюеров это инструкция, не песочница. Тулы `read`, `grep`, `glob`, `bash` доступны; `bash` запрещён для правок.

**Установка:** скопировать `skills/` и `agents/` в `~/.omp/agent/`. Механизм установки в репозитории ещё не реализован.

**Выключить:** удалить установленные файлы.

**Проверка:** реальным запуском. Постоянного теста нет: только ресурсы.
