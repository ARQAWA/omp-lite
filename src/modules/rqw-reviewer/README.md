# RQW Reviewer

Приёмка любой работы по словам владельца: код, план, аналитика. Находка бывает трёх видов: заказано и не сделано, сделано и не заказано, сделано не так, как заказано. Раздутое это лишнее: ревьюер показывает меньший вариант одной строкой. Сценарии «а если», неназванные способ и стиль, внешний мир и правила репозитория не проверяются. Кода нет: один профиль сабагента и три скилла.

**Цель:** 90-97% качества итога за минимум времени и кругов, не 100%. Правка, которая удлиняет ревью ради последних процентов, не принимается.

**Вход:** `/skill:blindreview` и `/skill:highreview`. Слова владельца после команды называют, что проверять. Оба входа работают одинаково и ведут в `skill://reviewer/SKILL.md`; он скрыт из каталога (`hide: true`). Ревью запускает основная сессия или сабагент, у которого есть тул `task`.

**Состав:**

- `agents/acceptor.md` — ревьюер, новый на каждый круг. Получает сдачу исполнителя как всё задание. Заявлениям исполнителя не верит: сам читает работу, сам выписывает требования и ограничения из слов владельца, сверяет заказ и работу в обе стороны. Три реплики владельца выборочно ищет в файле сессии; при `session: none` сверки нет, при `base: none` читает файлы из `Work`. Ответ: `CLEAN`, `FINDINGS` одной пачкой или `BROKEN`. Уровень находки `serious` или `note`; круг блокирует только `serious`. В шапке профиля нет `write` и `edit`.
- `skills/reviewer/SKILL.md` — процедура исполнителя. До сдачи он сам убирает незаказанное и доделывает заказанное. Сдачу пишет по форме: файл сессии, каталог, базовый коммит, объём, слова владельца дословно и по порядку, отменённое и отложенное, список работы, свои заявления. После сжатия слова владельца берёт из файла сессии, не из сводки. Ответ без строки на каждое заказанное и на каждый файл работы не вердикт. Верную находку чинит самой маленькой правкой. На неверную пишет возражение в блоке `## Round <n>` сдачи: находка решена (`settled`), снова её не открывают. Владельца зовёт, только когда ревьюер назвал лишней критичную часть. Принято: два чистых круга подряд, работа между ними не менялась. Предела кругов нет. Итоговый отчёт перечисляет решённые находки и `note`.
- `skills/blindreview/SKILL.md`, `skills/highreview/SKILL.md` — входы.

**Тулы профиля:** `read`, `grep`, `glob`, `bash`, `eval`, `task`, `web_search`.

**Модель:** ревьюер на `openai-codex/gpt-6.1-terra`, усилие `high`. Запасных моделей нет.

**Границы:** ревьюер ничего не правит, тесты и код не запускает, внешний мир не проверяет. Память OMP сабагенту не выключает: запрет стоит в промпте профиля. Сдачу пишет сам автор работы: пропущенную им реплику ревьюер не найдёт. Выборочная сверка с файлом сессии это сигнал, а не замок. Решённую находку закрывает сам автор работы. Файлов ревью нет: сдача живёт в тексте задания.

**Установка:** четыре записи в `install.manifest.json`: профиль идёт в `agents/`, скиллы в `skills/`. Прежний `agents/collector.md` стоит в `remove`. Зависимостей нет. Нужна новая сессия.

**Выключить:** удалить эти четыре файла из `~/.omp/agent`.

**Тест:** `bun test dev/tests/harness/rqw-reviewer`.
