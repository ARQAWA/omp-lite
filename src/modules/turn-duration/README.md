# turn-duration

Одна тусклая строка после каждого хода: сколько агент работал.

```text
⏱ 2m 4s
```

Счёт идёт от твоего ввода до конца работы агентского цикла, вместе с тулами.

Строка появляется после любого хода, короткого тоже. Прерванный или упавший ход строки не оставляет и часы сбрасывает. Ход без твоего ввода метки не получает. Команда, шелл-запуск и пустая строка хода не дают, но ввод всё равно ставит часы: если сразу после такой строки расширение запустит ход, метка захватит и это время.

Строка — это custom-сообщение сессии. Она только для твоего экрана: модель её не видит и ход из-за неё не запускается. Два замка. Первый: метку шлёт таймер после `agent_end`, когда агент уже простаивает, поэтому `sendMessage` её рисует и ничего не запускает. Раньше метка уходила посреди работы, и модель отвечала на неё. Второй: хук `context` вырезает метку из каждого запроса, в том числе после `--resume`, где она читается из файла сессии.

Источник: пакет `pi-response-duration` 1.0.1 (MIT, copyright 2026 tech-msc). Текст лицензии — [LICENSE](LICENSE). Переписан под OMP: там нет `agent_before_settle` и `registerEntryRenderer`, поэтому строка идёт через `sendMessage` и `registerMessageRenderer`.

**Вход:** `~/.omp/agent/extensions/turn-duration.js` и `turn-duration.LICENSE` рядом с ним. Файлы перечислены в [манифесте](../../../install.manifest.json).
