# turn-duration

Одна тусклая строка после долгого хода: сколько агент работал.

```text
⏱ 2m 4s
```

Счёт идёт от старта хода до конца работы агентского цикла, вместе с тулами.

Порог 30 секунд: короткие ходы молчат. Прерванный или упавший ход строки не оставляет. Ход, начатый расширением без твоего ввода, тоже молчит. Команда, шелл-запуск и пустая строка хода не дают, поэтому часы не сдвигают.

Строка — это custom-сообщение сессии. В историю она попадает и короткой пометкой уходит в контекст модели: отдельного канала только для экрана в OMP нет.

Источник: пакет `pi-response-duration` 1.0.1 (MIT, copyright 2026 tech-msc). Текст лицензии — [LICENSE](LICENSE). Переписан под OMP: там нет `agent_before_settle` и `registerEntryRenderer`, поэтому строка идёт через `sendMessage` и `registerMessageRenderer`.

**Вход:** `~/.omp/agent/extensions/turn-duration.js`. Механизм установки в репозитории ещё не реализован.
