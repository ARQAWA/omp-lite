# turn-duration

Одна тусклая строка после каждого хода: сколько агент работал.

```text
⏱ 2m 4s
```

Счёт идёт от твоего ввода до конца работы агентского цикла, вместе с тулами.

Строка появляется после короткого, прерванного или упавшего хода. Ход без твоего ввода метки не получает. Команда, шелл-запуск и пустая строка хода не дают, но ввод всё равно ставит часы: если сразу после такой строки расширение запустит ход, метка захватит и это время.

Строка — это custom-сообщение сессии. Таймер после `agent_end` отправляет её без нового хода или откладывает, пока агент занят. Хук `context` вырезает метку из каждого запроса, в том числе после `--resume`.

Редкие ограничения:
- Ввод при проверке простоя может направить метку в текущий ход.
- Переключение сессии может потерять отложенную метку.
- Отмена до старта не даёт метку и может оставить старые часы.

Источник: пакет `pi-response-duration` 1.0.1 (MIT, copyright 2026 tech-msc). Текст лицензии — [LICENSE](LICENSE). Переписан под OMP: там нет `agent_before_settle` и `registerEntryRenderer`, поэтому строка идёт через `sendMessage` и `registerMessageRenderer`.

**Вход:** `~/.omp/agent/extensions/turn-duration.js` и `turn-duration.LICENSE` рядом с ним. Файлы перечислены в [манифесте](../../../install.manifest.json).
