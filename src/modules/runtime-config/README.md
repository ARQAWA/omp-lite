# runtime-config

Сырой снимок. Полный нестандартный `config.yml`, 112 строк. Роли моделей, фильтр моделей `enabledModels` и скрытые провайдеры `disabledProviders`, память `mnemopi` с локальными эмбеддингами, предсказание промптов, тема и статусная строка, `find` выключен, проверка обновлений при старте выключена, transcript presenters включены.

**Вход:** файл целиком в `~/.omp/agent/config.yml`. Ключи: `omp://settings.md`, `omp://models.md`, `omp://mnemosyne-memory-backend.md`.

**Зависимости:** эндпоинт эмбеддингов `127.0.0.1:11434`.

**Выключить:** вернуть прежний файл.

**Тесты:** нет.
