# runtime-config

Полный нестандартный `config.yml`. Роли моделей, фильтр моделей `enabledModels` и скрытые провайдеры `disabledProviders`, память `mnemopi` с локальными эмбеддингами, предсказание промптов, тема и статусная строка, `find` выключен, проверка обновлений при старте выключена, карточки тулов показаны.

**Маршрутизация bash:** `bashInterceptor.enabled: true`.
Обычные чтение и поиск направляются специализированным тулам.
Встроенные правила OMP 18.18.8 сохранены.
К ним добавлено чтение через `sed -n`.
`ls` и `tree` направляются в `read`.
Родной `read` поддерживает деревья каталогов.
Правило `find` покрывает также перечисление без фильтров.
Данные получены через `omp config get bashInterceptor.patterns`.
Свои `patterns` заменяют встроенный список, не дополняют.
Источник: `omp://tools/bash.md`, `omp://tools/read.md`, `omp://settings.md`.

**Предел:** это предпочтение возможностей, не изоляция.
Потребители пайпов и код интерпретаторов могут пройти.
Блокировка зависит от доступности замещающего тула.
Перехват не гарантирует исчезновения попыток модели.
Он блокирует выполнение подходящих команд.

**Слепок:** фрагменты `config` манифеста вместе дают все настройки владельца. Установка по `INSTALL.md` заменяет ими конфиг целевой машины целиком; прежний конфиг уходит в копию. Секретов нет. Решение: D-046.

**Вход:** файл целиком в `~/.omp/agent/config.yml`, а блок памяти — фрагментом `mnemopi.yml` через [манифест](../../../install.manifest.json). Ключи: `omp://settings.md`, `omp://models.md`, `omp://mnemosyne-memory-backend.md`.

**Зависимости:** эндпоинт эмбеддингов `127.0.0.1:11434`.

**Выключить:** вернуть прежний файл.

**Тесты:** `bun test dev/tests/harness/runtime-config`.
