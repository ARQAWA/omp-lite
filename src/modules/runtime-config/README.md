# runtime-config

Сырой снимок нестандартного рантайм-конфига OMP. Файл скопирован побайтово, без правок.

**Источник:** `~/.omp/agent/config.yml`, снят 2026-11-08.

**Наблюдаемое поведение:** роли моделей, память `mnemopi` с локальными эмбеддингами, предсказание промптов в композере, тема, статусная строка и прочие личные настройки владельца.

**Вход OMP:** файл целиком кладётся в `~/.omp/agent/config.yml`.

**Ресурсы и зависимости:** нет.

**Подключение и отключение:** замена файла с бэкапом прежнего. Отключение — вернуть прежний файл.

**Тесты:** нет. Это данные, не код.
