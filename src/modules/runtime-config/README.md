# runtime-config

Полный нестандартный `config.yml`. Роли моделей, фильтр моделей `enabledModels` и скрытые провайдеры `disabledProviders`, память `mnemopi` с локальными эмбеддингами, предсказание промптов, тема и статусная строка, `find` выключен, проверка обновлений при старте выключена, карточки тулов показаны.

**Чтение:** `read.summarize.enabled: true` включает структурные сводки кода без селектора. Сводка скрывает части файла и показывает подсказку для чтения диапазонов. Сторож `base-tools` пока ожидает `false` и предупреждает об изменении настройки.

**Маршрутизация bash:** `bashInterceptor.enabled: true`.
Обычные чтение и поиск направляются специализированным тулам.
Встроенные правила OMP 18.18.8 сохранены.
К ним добавлено чтение через `sed -n`.
`ls` и `tree` направляются в `read`.
Родной `read` поддерживает деревья каталогов.
Правило `find` покрывает также перечисление без фильтров.
Данные получены через `omp config get bashInterceptor.patterns`.
Свои `patterns` заменяют встроенный список, не дополняют.

**Предел:** это предпочтение возможностей, не изоляция.
Потребители пайпов и код интерпретаторов могут пройти.
Блокировка зависит от доступности замещающего тула.
Перехват не гарантирует исчезновения попыток модели.
Он блокирует выполнение подходящих команд.

**Слепок:** фрагменты `config` манифеста вместе дают все настройки владельца. Установка по `INSTALL.md` заменяет ими конфиг целевой машины; прежний конфиг уходит в копию. Существующий `modelRoles.default` сохраняется; если его нет, берётся значение слепка. Секретов нет. Решения: D-046, D-072.

**Модели:** `enabledModels` перечисляет десять точных моделей четырёх провайдеров: `anthropic`, `openai-codex`, `opencode-go`, `openrouter`. `providers.openrouterVariant: floor` дописывает `:floor` к запросам OpenRouter: без него тариф flex недоступен. Ключ OpenRouter в слепок не входит. На каждой машине он кладётся руками в `~/.omp/agent/models.yml`: `providers.openrouter.apiKey`. Без ключа модель OpenRouter в списках не появляется. Роль `perCall` несёт 79 моделей трёх провайдеров и одну модель `openrouter`. Решение: D-065.

**Сабагенты:** `task.perCallModel: "on"` разрешает модель на каждый вызов `task`; усилие идёт хвостом `:level` в строке модели. `task.enableEffort: false`: поле `effort` знает только `lo/med/hi`. Кавычки у `"on"` нужны: голое `on` YAML читает как `true`. Грант даёт роль чата вне настроек проекта, модель выбранного встроенного или пользовательского агента либо текущая модель родителя. Модель должна быть доступной чат-моделью и проходить allowlist. Шаблоны `*`, каталог и ключи сами гранта не дают. `task.agentModelOverrides`: `scout` на `openai-codex/gpt-6.1-terra:xhigh`, `sonic` на `openai-codex/gpt-6.1-terra:medium`. `task.disabledAgents`: `reviewer`, `security-reviewer`; приёмка идёт своими сабагентами `collector` и `acceptor` модуля `review`. Тест: `dev/tests/harness/runtime-config/subagents.test.js`.

**Вход:** файл целиком в `~/.omp/agent/config.yml`, а блок памяти — фрагментом `mnemopi.yml` через [манифест](../../../install.manifest.json).

**Зависимости:** эндпоинт эмбеддингов `127.0.0.1:11434`.

**Выключить:** вернуть прежний файл.

**Тесты:** `bun test dev/tests/harness/runtime-config`.
