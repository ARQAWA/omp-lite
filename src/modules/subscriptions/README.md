# subscriptions

Метки лимитов подписок в статуслайне OMP.

```text
CC 55% · CX 88% · Go 86%/93%
```

| метка | провайдер | окно | смысл |
| --- | --- | --- | --- |
| `CC` | anthropic | 7d | осталось недельного лимита |
| `CX` | openai-codex | 7d | осталось недельного лимита |
| `Go` | opencode-go | 7d + monthly | недельный и месячный лимит |

Печатается остаток. Подписки без данных не печатаются. Порядок задан именами ключей `10-cc`, `20-cx`, `30-go`: сегмент `status` сортирует метки по имени. Метки уходят в родной сегмент `status`, цвета не выставляются: OMP чистит ANSI из `ctx.ui.setStatus`.

Данные берутся из документированной команды `omp usage --json`. Обновление при старте и раз в пять минут. Ошибка чтения оставляет прошлые значения.

**Вход:** `~/.omp/agent/extensions/subscriptions.js`.

**Выключить:** удалить файл.

**Тесты:** `bun test dev/tests/harness/subscriptions`.
