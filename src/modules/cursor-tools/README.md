# cursor-tools

Обёртки над родными тулами `grep` и `bash` под именами omp.

Переносит аргументы поиска, к которым привыкли агенты курсора, не меняя имена тулов.

## Наблюдаемое поведение

`grep` принимает `-A`, `-B`, `-C`, `-i`, `case`, `type`, `multiline`, `glob`, `head_limit`, `offset`, `skip` и `output_mode` с тремя значениями: `content`, `files_with_matches`, `count`.

На простых путях поиск идёт через родной движок `@oh-my-pi/pi-natives`. Это даёт контекст и тип на один вызов, без правки общих настроек.

На путях со схемой, в архивах, с селектором строк или списком через `;` вызов уходит в родной тул. Аргументы, которых там нет, возвращают явную ошибку, а не другой результат.

Страница режется по целым совпадениям, продолжение названо в ответе. Бюджет страницы — 15000 символов.

`bash` принимает `working_directory` и переводит его в `cwd`, если `cwd` не задан. `bash` принимает `block_until_ms`. Ноль значит «в фон сразу» и переводится в `async: true`. Любое другое число отклоняется: родной тул читает общий порог после `await`, поэтому подмена на вызов гоняется с параллельными вызовами.

## Вход OMP

Модуль — обычное расширение: экспортирует функцию, получает api расширений и регистрирует два тула с именами `grep` и `bash`, перекрывая родные.

Подключение на время проверки:

```bash
omp -e src/modules/cursor-tools/index.js
```

## Настройка

При загрузке модуль включает `edit.mode: apply_patch` в рантайме. Сохранённые настройки не меняются.

Режим действует только в тех сессиях, где модуль загружен. Механизм установки пока не описан, поэтому обычные сессии его не получают: [INSTALL.md](../../../INSTALL.md).

На провайдере со свободным форматом тул может объявить второе имя `apply_patch`; вызов по `edit` всё равно работает.

## Отключение

Убрать `-e src/modules/cursor-tools/index.js` из запуска. Родные `grep` и `bash` вернутся сами, режим правок станет прежним.

## Ограничения

- `block_until_ms` с положительным числом не поддерживается.
- `notify_on_output`, `description` и поля smart-mode курсора не поддерживаются.
- `working_directory` без своего `cwd` работает как `cwd`.
- Поиск по архивам идёт родным тулом: контекст, `type` и режимы вывода там недоступны.
- Страница `content` режется по совпадениям, контекстные строки едут вместе с ними.

## Тесты

`bun test dev/tests/harness/cursor-tools`

Проверяют маршрут вызова, разбор аргументов, вывод трёх режимов, пагинацию, ветку родного тула и перевод `working_directory` и `block_until_ms`.
