# cursor-tools

Обёртки над родными тулами `grep`, `bash`, `glob` и `read` под именами omp.

Переносят аргументы, к которым привыкли агенты курсора, не меняя имена тулов и не отнимая родные возможности.

## Наблюдаемое поведение

`grep` принимает `-A`, `-B`, `-C`, `-i`, `type`, `multiline`, `glob`, `head_limit`, `offset` и `output_mode` с тремя значениями: `content`, `files_with_matches`, `count`. Плюс родной `gitignore`. Дублей нет: `case` заменён на `-i`, `skip` на `offset`.

На простых путях поиск идёт через родной движок `@oh-my-pi/pi-natives`. Это даёт контекст и тип на один вызов, без правки общих настроек.

На путях со схемой, в архивах и с селектором строк вне одного хост-файла вызов уходит в родной тул. Аргументы, которых там нет, возвращают явную ошибку, а не другой результат. `offset` там переводится в родной `skip`; на одном файле модуль сам срезает первые совпадения.

Файл с селектором строк идёт своим движком: диапазон фильтруется после поиска, лимит родного тула в 200 совпадений не действует. Список существующих хост-путей через `;`, запятую или пробел ищется движком по одному пути, поэтому 200 не действует и там. Существующий путь ищется движком как есть, даже если похож на селектор, маску или архив: `a.ts:10-20`, `a[b].txt`, `app/[id]`. Остальные селекторы (архивы, URL) идут родным тулом.

Страница режется по целым совпадениям, продолжение названо в ответе. Каждое совпадение несёт всё своё окно `-A/-B/-C`, на границе страницы тоже. Чужое совпадение внутри окна печатается как строка контекста `-`: своей записью оно идёт на своей странице. Так `head_limit: 1` показывает ровно одно совпадение `:`, а строки окна не теряются. Если оба совпадения на одной странице, строка печатается один раз, как совпадение. Бюджет страницы — 15000 символов. Запись больше бюджета теряет дальние контекстные строки, обрыв помечен `…`. Строка совпадения остаётся всегда и целиком: модуль её не режет.

Лимит длины строки задаёт настройка `tools.outputMaxColumns`. В нашем конфиге она `0`: лимита нет, большой ответ уходит в артефакт по настройкам спилла. При положительном значении движок режет строку окном вокруг совпадения и ставит в конце `[col N]`, как родной тул.

Файл больше 4 МиБ в обходе каталога движок читает только с начала (`omp://tools/grep.md`). Если в таком файле нашлось совпадение, ответ называет файл и советует искать по его пути: названный файл движок читает целиком.

Список через запятую или пробел, где какого-то пути нет, идёт родным тулом: он сам раскрывает такие списки.

`bash` принимает `working_directory`, `block_until_ms`, а также родные `timeout`, `pty`, `name` и `ready`. `working_directory` переводится в `cwd`, если тот не задан; `cwd` из схемы убран как дубль. Ноль в `block_until_ms` переводится в `async: true`; поле `async` из схемы убрано как дубль. Любое другое число отклоняется: родной тул читает общий порог после `await`, поэтому подмена на вызов гоняется с параллельными вызовами. Параметры `command`, `working_directory` и `block_until_ms` несут описания из схемы `Shell` курсора.

Перед исходным описанием `bash` стоит приоритет файловых тулов.
Он прямо запрещает пробовать файловые команды оболочки.
Штатный перехват задан в [runtime-config](../runtime-config/README.md).

Описания `read` и `glob` задают пакетирование.
Нужные независимые вызовы собираются в один ответ.
Случайные пути и повторное чтение неизменного содержимого запрещены.
Числового лимита пакета нет.
`grep` и `bash` не менялись.

`glob` принимает курсорные `glob_pattern` и `target_directory`, а также родные `hidden`, `gitignore` и `limit`. Курсорные поля склеиваются в один родной `path`; шаблон без `**/` получает этот префикс, как в курсоре: `src/*.js` ищется как `**/src/*.js`, `package.json` как `**/package.json`. Ведущий `./` отбрасывается. Префикс не ставится там, где он невозможен: абсолютный путь, `../`, `~`, URL, список через `;`. Существующий каталог и существующее имя со знаками маски, например `a[b].txt`, остаются путём: каталог показывает свои файлы, как у родного тула. Обычные файлы идут списком, новые сверху: порядок по времени изменения. Родной `path` из схемы убран как дубль.

`read` принимает курсорные `offset` и `limit`. Срез точный: путь дополняется селектором `:A-B:raw`, потому что родной селектор расширяет окно. Отрицательный `offset` без `limit` даёт последние строки; с `limit` модуль сначала считает строки. Селектор внутри `path` вместе с `offset` отклоняется. Существующий файл с именем вроде `report:12` читается как файл.

Для `xd://` путь темы остаётся неизменным.
Срез применяется к возвращённому тексту документа.
Отрицательный `offset` также поддерживается.
Обычные файлы и остальные схемы сохраняют прежний маршрут.

## Вход OMP

Модуль — обычное расширение: экспортирует функцию, получает api расширений и регистрирует четыре тула с именами `grep`, `bash`, `glob` и `read`, перекрывая родные.

Установка: каталог `extensions/cursor-tools` по [манифесту](../../../install.manifest.json) и [INSTALL.md](../../../INSTALL.md).

Подключение на время проверки:

```bash
omp -e src/modules/cursor-tools/index.js
```

## Настройка

При загрузке модуль включает `edit.mode: apply_patch` в рантайме. Сохранённые настройки не меняются.

Режим действует только в тех сессиях, где модуль загружен. После установки по контракту его получают все новые сессии.

На провайдере со свободным форматом тул может объявить второе имя `apply_patch`; вызов по `edit` всё равно работает.

## Отключение

Убрать `-e src/modules/cursor-tools/index.js` из запуска. Родные тулы вернутся сами, режим правок станет прежним.

## Ограничения

- `block_until_ms` с положительным числом не поддерживается.
- `notify_on_output`, `description` и поля smart-mode курсора не поддерживаются.
- `read` с `offset` отдаёт сырой текст без номеров строк.
- `glob` сортирует по mtime только обычные файлы; URL и архивы идут родной выдачей.
- На родном маршруте `offset` листает файлы, а в одном файле срезает совпадения по тексту.
- Отрицательный `offset` с `limit` стоит двух вызовов.
- Поиск по архивам идёт родным тулом: контекст, `type` и режимы вывода там недоступны.
- Хост-файл с селектором и хост-список идут движком: сбор до 100000 совпадений, страница режется по бюджету.
- Страница `content` режется по совпадениям, окно контекста едет вместе с каждым.
- Файл больше 4 МиБ без совпадений в первых 4 МиБ обход каталога не покажет: движок о нём не сообщает. Такой файл ищи по его пути.
