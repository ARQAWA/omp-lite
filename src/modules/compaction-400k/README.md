# compaction-400k

Сырая выдержка из рантайм-конфига. Пороги сжатия контекста ровно на 400 000 токенов. Скопировано без правок.

**Источник:** блок `compaction` файла `~/.omp/agent/config.yml`.

**Наблюдаемое поведение:** модель сжимает контекст точно на 400k токенов. Охвачены подписочные Claude и `opencode-go/deepseek-v4.1-flash`.

**Вход OMP:** ключ `compaction.modelThresholds` в `~/.omp/agent/config.yml`.

**Ресурсы и зависимости:** нет.

**Подключение и отключение:** перенос блока в конфиг. Отключение — удалить блок.

**Тесты:** нет. Это данные, не код.
