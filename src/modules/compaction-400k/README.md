# compaction-400k

Сырой снимок. Выдержка `compaction.modelThresholds`: 16 моделей, значение `f400000` — точный порог 400k. Покрыты Claude, opencode-deepseek, GPT Sol и Terra, `deepseek/deepseek-flash`.

**Вход:** ключ `compaction.modelThresholds` в `~/.omp/agent/config.yml`. Полный конфиг — в [runtime-config](../runtime-config/README.md).

**Выключить:** удалить записи.

**Тесты:** нет.
