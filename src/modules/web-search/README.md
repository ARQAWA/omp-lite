# web-search

Сырая копия рабочего расширения. Живой веб-поиск через бэкенд ChatGPT Codex. Пять файлов скопированы побайтово.

**Источник:** `~/.omp/agent/extensions/codex-web-run/`.

**Наблюдаемое поведение:** расширение подменяет штатный `web_search`. Модель сама вызывает `web.run` в несколько раундов. Возвращает текст страниц и источники.

**Вход OMP:** каталог `~/.omp/agent/extensions/codex-web-run/`. Нужен вход `openai-codex`.

**Ресурсы и зависимости:** `web-run.schema.json` рядом с `index.js`.

**Подключение и отключение:** пустой файл `disabled` в каталоге возвращает штатный `web_search`.

**Тесты:** нет. Копия без правок.
