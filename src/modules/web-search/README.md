# web-search

Подменяет `web_search` циклом `web.run` на `gpt-6-luna`. Потолки: 4 раунда, 8 вызовов. Перед запросом планировщика и после выборки проверяет UTF-8 JSON накопленного `input`: при превышении 2 МиБ возвращает добытое, включая последнюю выборку.

Тайм-аут или ошибка потока планировщика после получения данных: результат с пометкой `[incomplete]`.

**Вход:** `~/.omp/agent/extensions/codex-web-run/`, нужен вход `openai-codex`.

**Выключить:** пустой файл `disabled` рядом с `index.js`, затем новая сессия OMP. Встроенный поиск доступен, если включён.

**Тесты:** `bun test dev/tests/harness/web-search/web-search.test.js`.
