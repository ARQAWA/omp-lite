# compactions

Счётчик компакшенов сессии в статуслайне.

```text
cmp 3
```

Считает записи типа `compaction` в истории сессии. Значит переживает перезапуск и продолжение сессии. Обновляется при старте, после компакшена, ветвления и переключения дерева.

**Вход:** `~/.omp/agent/extensions/compactions.js`.

**Выключить:** удалить файл.

**Тесты:** `bun test dev/tests/harness/compactions`.
