# compactions

Счётчик компакшенов сессии в статуслайне.

```text
cmp 3
```

Считает записи типа `compaction` во всей истории сессии. Значит переживает перезапуск и продолжение сессии. Обновляется при старте, переключении сессии, после компакшена и ветвления. Переключение дерева не меняет число записей, поэтому хук `session_tree` не нужен.

**Вход:** `~/.omp/agent/extensions/compactions.js`.

**Выключить:** удалить файл.

**Тесты:** `bun test dev/tests/harness/compactions`.
