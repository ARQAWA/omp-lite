# skill-alias

Расширение OMP. Превращает `/имя` в нативный `/skill:имя`. Работает, только если навык существует. Команды из `getCommands()` не перекрывает. Встроенные и файловые команды может перекрыть одноимённый навык.

**Вход:** `~/.omp/agent/extensions/skill-alias.js`.

**Выключить:** удалить файл.

**Тесты:** `bun test dev/tests/harness/skill-alias`.
