# dyslexia

Расширение OMP. Передаёт правило дислексии модели отдельным скрытым сообщением после запроса. Оно сохраняется в файле сессии, но не показывается в интерфейсе и не дописывается в сообщение владельца.

**Вход:** `~/.omp/agent/extensions/dyslexia.js`.

**Текст правила:** константа `BLOCK`. Сжатие хранит все правила исходного текста: предложение до 8 слов, абзац до 4 предложений, жирное главное, короткие шаги, простой русский на «ты», нумерованные списки, строчные буквы, мало спецсимволов, приоритет над прочими правилами общения. Последняя строка: смешанное или неясное сообщение, только чтение и один вопрос про правку. Она повторяет блок `<mixed_requests>` правила `communication-main` рядом с текстом владельца (D-057).

**Хук:** `before_agent_start`. Срабатывает перед запросом и при доставке очереди, включая steering и `/skill:`. Сабагенты правило не получают. При `revive` OMP отбрасывает результат хука. Работает там, где OMP грузит расширение: интерактивный режим, RPC, `omp -p`.

**Выключить:** удалить файл.

**Тесты:** `bun test dev/tests/harness/dyslexia/dyslexia.test.js`.
