# dyslexia

Расширение OMP. Дописывает правило дислексии в конец отправленного сообщения. Текст правила дословный из MyP.

**Вход:** `~/.omp/agent/extensions/dyslexia.js`.

**Пропуски:** сабагенты, команды `/`, `!`, `$`, пустой текст, повторная вставка. Работает в интерактивной отправке и RPC; print-режим не покрыт.

**Выключить:** удалить файл.

**Тесты:** `bun test dev/tests/harness/dyslexia`.
