# dyslexia

Расширение OMP. Дописывает правило дислексии в конец каждого пользовательского сообщения при сборке запроса. В истории и интерфейсе вставки нет.

**Вход:** `~/.omp/agent/extensions/dyslexia.js`.

**Пропуски:** сабагенты, повторная вставка. Работает в интерактивной отправке и RPC; print-режим не покрыт.

**Выключить:** удалить файл.

**Тесты:** `bun test dev/tests/harness/dyslexia`.
